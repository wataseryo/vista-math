# Sprint 6 自己評価: 図(diagram) P2 — 残り12問(基本図形)

Sprint 4-5（P0/P1、7問）に続く最終フェーズ。u6-plane 19問全てにdiagramが揃った。

## 実施内容

### 1. 基本図形の共通生成関数を作成（著者ツール、実行時コードではない）

Codexの元計画で「同型問題が増える段階で動的生成へ移行する」とされていた通り、
今回9問が同じ3パターン（平行四辺形・三角形・台形の単純な公式適用/逆算）だったため、
一回限りの生成スクリプト（`parallelogram()`/`triangle()`/`trapezoid()`関数）で
SVG markup文字列を生成し、静的データとして書き込んだ。生成関数自体はリポジトリに
含めず、出力結果のみをデータに埋め込んでいる（アプリのランタイムには一切影響しない）。

### 2. 対象12問と設計方針

| ID | 内容 | 設計上の工夫 |
|---|---|---|
| u6_plane_trial_001〜003 | 平行四辺形/三角形/台形の基本(底辺・高さ既知) | 図形+寸法線のみ |
| g6_plane_001〜003 | 同上の数値違い | 同上 |
| g6_plane_004 | 面積36cm²・底辺9cmから高さを逆算 | 底辺と面積を図に明記、**高さは「？」表示**（答えを見せない） |
| g6_plane_005 | 面積60cm²・底辺12cmから高さを逆算 | 同上 |
| g6_plane_008 | 面積48cm²・上底4cm・高さ6cmから下底を逆算 | 上底・高さ・面積を明記、**下底は「？」** |
| g6_plane_012 | 三角形(8,6)と面積が等しい平行四辺形(底辺8)の高さを求める | 三角形と平行四辺形を「＝」で並べ、平行四辺形の**高さのみ「？」**。三角形の面積(24cm²)は解説の中間値のため図には数値を出さず「＝」の視覚的等価のみ示した |
| g6_plane_013 | 底辺2倍・高さ同じの三角形2つ、Bの面積15cm²からAを求める | B・Aを並べ、高さが同じであることを破線で明示。Aの面積は「？」 |

その未知量には数値を一切描かず「？」で統一した。Sprint 4での`g6_plane_015`の反省
（出題図に結論を含めない）を踏襲。

### 3. データへの挿入方法

各問題の`id:`行から次の`},`（閉じ括弧、列0開始）を機械的に検索し、その直前に
`diagram: {...}`ブロックをスクリプトで挿入。手動でのファイル全体書き換えは行っていない。

## Codexレビュー結果(2026-09-21)

読み取り専用の独立レビューを実施。**1件(Normal)の指摘、対応済み。**

- **指摘**: `g6_plane_012`の図で、三角形(底辺8×高さ6÷2=24cm²相当の描画)と平行四辺形(底辺8×高さ70px相当)の**描画面積が実際には5/3倍異なっており**、問題文の「面積が等しい」という前提と矛盾していた
- **対応**: 平行四辺形の描画高さを三角形と揃えた上で、「※ 図の高さは実際の比率ではありません」という注記を追加。
  （根本的な制約: この問題は幾何的に「三角形の高さ÷2＝平行四辺形の高さ」という関係が数値に関わらず常に成り立つため、真に正確な縮尺で描くと答え(3cm＝6cmの半分)の比率がそのまま見えてしまう。注記で「縮尺通りではない」ことを明示する方式で解決）
- その他4項目は指摘なし: 12問中どの図にも数値の矛盾なし、答えの非開示は全問で徹底、013の「底辺×2」・014の1:3縮尺表示は「問題文に明記された既知情報の可視化」として妥当と判定
- diagram以外のフィールド（text/answer/hint/solution等）への意図しない変更もなし
