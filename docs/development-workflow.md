## 実構成

index.htmlが画面を、css/style.cssが表示を、js/app.jsが教材・採点を担当する。js/catalog.jsは教材の選択と件数、js/storage.jsは端末内の学習記録とJSONバックアップ、js/navigation.jsはタブ内の学習位置・ブラウザ履歴を担当する。data/problems/*.jsが実問題、data/problems.jsは集約専用。サーバーDB・アカウント・端末間同期は未実装。

## 問題追加前後の確認

1. docs/content-authoring.mdの形式と読み込み手順に従う。
2. npm installで開発用依存を取得する（現在の実行時アプリにはnpm依存なし）。
3. npm run checkでデータ構造とNode回帰テストを実行する。
4. python3 -m http.server 8765 --bind 127.0.0.1で起動し、npm run test:browserを実行する。Google Chromeを使用する。テストは独立したブラウザコンテキストの記録を使う。
5. 全202問の構造検証は算数の正解の保証ではない。新問題の答え・解説は別途独立確認する。

## 保存と運用の境界

学習記録は同じ配信元の端末・ブラウザ内のみ。JSONバックアップで手動移行できるが、認証付きクラウド同期や生徒ごとの記録分離はない。家族・塾生が共用すると記録は共通。複数タブで同時学習しない。競合・保存容量不足・ブラウザ拒否時は警告し、そのセッションのバックアップを取得する。

既存履歴を無断で切り捨てないため全解答履歴は保持する。画面の履歴ドットは直近10回に制限するが、長期的な履歴容量は増える。大量運用前には全期間集計＋直近履歴への移行またはサーバー保存を、既存記録の移行検証付きで別途設計する。旧データに存在しない解答日時・学年別の古い水槽記録は推測して補完しない。

学習位置はタブのsessionStorageとブラウザhistoryに保存し、直近80経路・約1.5MBまで。閉じたタブの再開や他端末への位置同期を保証しない。履歴の学習位置を削除しても永久の学習記録は削除しない。
