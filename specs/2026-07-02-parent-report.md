# 製品仕様書: 保護者・塾向け学習レポート

## プロダクト概要

保護者や塾の指導者が「この子が何をどれだけ理解しているか」を一画面で把握できるレポート画面を提供する。
対象ユーザーは小学5・6年生の保護者および塾の指導者。
既存の `vista_stats` / `vista_history` を読み取るだけで、データ構造の変更は行わない。
有料化・塾向け訴求の布石となる機能。

## スプリント計画

### Sprint 1: レポート画面の完成（既存実装の差分修正 + 拡充）

#### 背景
`renderReport()` と `report-screen` はすでに存在する。
本 Sprint ではユーザー要求との差分を埋め、品質を仕上げる。

#### 差分修正・拡充内容

**[差分1] 学習継続日数の追加**
- 現状: 最終学習日（`vista_last_ts`）のみ表示
- 要求: 初回解答日からの継続日数（経過日数）を表示
- 対応: `recordProblemAttempt` で初回のみ `vista_first_ts` に Date.now() を記録する。
  レポートでは `(今日 - vista_first_ts) / 86400000` を切り上げた日数を「学習継続日数」として表示する。
  `vista_first_ts` が存在しない既存ユーザーは「—」と表示する。

**[差分2] 最近間違えた問題を 3件→5件 に拡張**
- 現状: `recentWrongSlice = recentWrong.slice(0, 3)`
- 要求: 5件表示（`slice(0, 5)`）

**[差分3] 次に復習すべき単元を 1件→最大2件 に拡張**
- 現状: TOP1 のみ
- 要求: TOP1〜2 件を並べて表示。それぞれに「復習する」ボタン

**[差分4] おすすめ復習画面への導線を追加**
- 現状: 受験コース画面（exam-mode）のみに導線ボタンがある
- 要求: おすすめ復習画面（recommended-review-screen）にも「学習レポートを見る」ボタンを追加

## セクション仕様詳細

### セクション1: 全体サマリー

| 表示項目 | データ源 | 計算方法 |
|---------|---------|---------|
| 総解答数 | `vista_stats` の g{grade}_exam_* を集計 | 全 total の合算 |
| 全体正答率 | 同上 | correct/total × 100（%、整数） |
| 学習継続日数 | `vista_first_ts`（新規追加） | ceil((today - firstTs) / 86400000) 日 |

### セクション2: カテゴリ別正答率バーグラフ

- PRACTICE_CATS の 8分野すべてを縦並びで表示
- 各行: カテゴリ名（アイコン付き） + 横バー + 正答率%
- バー色: 80%以上→緑、50〜79%→黄、50%未満→赤（CSS クラスで制御）
- 未挑戦カテゴリ: バー幅 0%、「未挑戦」テキスト表示

### セクション3: 苦手単元 TOP3

- `vista_history` を `lessonUnit` 別に集計
- 集計条件: 試行数 3回以上
- ソート: 正答率昇順
- 表示: 順位バッジ + 単元名 + 正答率 + 解答数（correct/total問 正解）

### セクション4: 最近間違えた問題

- `vista_history` の各 probId について最終 attempt が false のものを抽出
- `PRACTICE_PROBLEMS` の `title` 先頭30文字を表示（超える場合は「…」を付ける）
- カテゴリ名（PRACTICE_CATS.title）と lessonUnit 名も表示
- 最大 5件

### セクション5: 次に復習すべき単元

- 苦手 lessonUnit TOP1（試行数 >= 2、正答率 < 70%）を優先
- lessonUnit に該当がない場合は苦手カテゴリ TOP1 を使用
- 最大 2件（TOP1 と TOP2）を並べて表示
- 「復習する」ボタン → `wrGoToCat(catId)` で演習問題へ遷移

### セクション6: 一言コメント

| 条件 | コメント文（例） |
|------|---------------|
| 全体正答率 80%以上 | 「全体的によく解けています。苦手な「{苦手単元名}」をさらに強化しましょう。」 |
| 全体正答率 50〜79% | 「着実に力がついています。「{苦手単元名}」の復習を集中的にやってみましょう。」 |
| 全体正答率 50%未満 | 「「{苦手単元名}」を中心に、基本問題から丁寧に取り組みましょう。」 |
| 苦手単元が存在しない場合 | 単元名部分を「苦手分野」と表示 |

## データ構造（参考・変更なし）

```
vista_stats   = { "g{grade}_exam_{catId}": { correct: N, total: N }, ... }
vista_history = { "{probId}": [true, false, true, ...], ... }
vista_last_ts = "{timestamp_ms}"         // 最終解答タイムスタンプ（既存）
vista_first_ts = "{timestamp_ms}"        // 初回解答タイムスタンプ（新規追加）
```

`vista_first_ts` は `recordProblemAttempt` 内で、キーが存在しない場合のみ書き込む。

## 制約・前提条件

- index.html 1ファイル構成を維持する（CSS・JS をそれぞれの外部ファイルに書く）
- CSS ライブラリ・Chart.js 等の外部ライブラリは使用しない
- バーグラフは CSS のみ（inline style で width を動的に設定）で実装する
- `vista_stats` / `vista_history` の既存データ構造を変更しない
- 解答が 5問未満の場合は「まだ学習履歴がありません」相当のメッセージを表示し、クラッシュしない
- スマホ（幅 375px 以上）でレイアウトが崩れないこと
- @media print スタイルを追加し、印刷時に余白・フォントサイズが読みやすいこと
- AI・外部 API は使用しない（一言コメントはルールベース）

## 未解決の仮定

- 「学習継続日数」は「初回解答日から今日まで」の経過日数（連続学習かどうかは問わない）と仮定した
- `vista_first_ts` が存在しない既存ユーザーは「—」と表示する（過去データを遡って推定しない）
- 最近間違えた問題の「直近5件」は `vista_history` のオブジェクト列挙順（挿入順）の後ろから取ると仮定した
- おすすめ復習画面への導線ボタンは、同画面の `rr-body` の下（コンテンツ末尾）に配置すると仮定した
- 「次に復習すべき単元 2件目」が存在しない場合は 1件のみ表示する
