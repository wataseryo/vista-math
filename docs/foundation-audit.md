# VISTA 基盤査定・運用境界

2026-10-12 / Codexチーム（Planner・実装・独立レビュー・ブラウザEvaluator）

## 構成と対応

現状は静的Webアプリ。サーバーAPI・DB・ログインはない。今回は問題追加前の安全性を整え、クラウド化は別工程とした。

- 学習記録をバージョン付き保存へ移行。旧キーと読めない原文を保護し、型・数値を検証。保存拒否・容量不足・別タブ競合を通知する。
- JSONバックアップの保存・検証付き置換復元を追加。取消・不正ファイル・保存失敗で正常記録を壊さない。
- 教材カタログで学年・コース・カテゴリ・関連教材を選択。件数を実データから算出し、食塩水など明示教材への移動を修正。
- 問題から教材への寄り道、ブラウザ戻る/進む、再読込で入力・結果・解説・位置を復元。難問・体験問題も対象。復元時に再採点せず、重複クリックによる二重計上を防ぐ。
- 復習・レポートの学年混入を修正。難問記録を別表示し、日時がない旧記録を推測で新しい記録扱いしない。
- 水槽Lv3の満水/排水問題で時間を切り上げていた誤りを修正。割り切れる流量を生成し、答えと説明を正確にする。
- 問題ファイルの読込/集約漏れ・重複ID・分類/単元参照・必須項目を自動検査する仕組みと追加手順を整備。

## 運用上の残る境界

学習記録は同じ配信元の同じ端末・ブラウザ内。共用端末では利用者別に分離されず、ブラウザデータ削除で失われる。定期バックアップが必要。別端末同期・生徒別管理・認証・決済・サーバーバックアップは未実装で、複数生徒への本格提供前に別途設計する。

同時に複数タブで回答する運用には対応しない。古いタブによる上書きを検出して停止するが、同時書込の厳密なトランザクションはブラウザlocalStorageでは保証しない。

全解答履歴は既存記録保護のため保持する。表示は直近10回、画面履歴は直近80経路・約1.5MBに制限するが、学習記録そのものは増え続ける。大量・長期運用には集計圧縮かサーバー保存の設計が必要。

教材の構造検査合格は数学的な正答保証ではない。既存202問中75問は旧解説書式の警告を残す。今回、全問の表示は確認するが全解説の数学的再監査は行わない。新規問題は独立した答え・解説レビューを必須とする。
