## 本スプリントとは無関係の発見(調査の上、軽微と判明・修正済み)

全Playwrightスイート(`npx playwright test`)を実行したところ、今回のスプリントとは無関係に3件の既存テストが失敗していた(`tests/navigation.spec.cjs`×2、`tests/learning-extras.spec.cjs`×1、いずれも`.btn-prac-topic`というセレクタのタイムアウト)。

調査の結果、**実際のアプリは正常に動作しており、テストのセレクタが古いままだっただけ**と判明した。

- `.btn-prac-topic`ボタンは2026-10-14のコミット`812a479`(「Remove duplicate トピックで学ぶ button in exam practice detail view」、重複ボタンの削除)で意図的に削除され、後継の`.prac-topic-link`(下部カード)に一本化されていた。CSS(`css/style.css:644`)にだけ定義が残っていた。
- `git merge-base --is-ancestor`で812a479が本セッションの全コミットの祖先であることを確認し、今回のスプリントとは無関係と判断。
- 念のため、実際に`.prac-topic-link`経由で「問題入力中にトピック画面へ寄り道→戻る」操作を手動で検証したところ、入力値(123)・画面タイトルとも正しく復元された。**機能は壊れておらず、重複採点等のリスクもない。**
- 3件のテストファイルのセレクタを`.btn-prac-topic`→`.prac-topic-link`に修正し、全19件のPlaywrightテストが合格することを確認した(`tests/navigation.spec.cjs`、`tests/learning-extras.spec.cjs`)。

教訓: このセッションを通じて、体験問題の戻り先ボタン(`#u6-calc-nav`等)に関するテストの思い込みミスを複数回踏んでいる。既存のPlaywrightスイートは`npm test`(Nodeのみ)に含まれないため、コンテンツスプリントのたびに自動では流れない。スプリント完了条件に`npm run test:browser`相当のフルスイート実行を含めることを今後検討したい。
